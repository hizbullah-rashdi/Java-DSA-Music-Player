# Java DSA Music Player

A desktop-based music player application developed in Java using Data Structures and Algorithms concepts. The project demonstrates playlist management, file handling, and object-oriented programming principles.

## Features

- Add and manage songs in playlists
- Play and organize music tracks
- Search songs easily
- Simple and user-friendly interface
- Uses Data Structures for efficient management

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- Data Structures & Algorithms
- Java Swing / JavaFX (if used)

## Project Concepts

- Arrays / ArrayList
- Linked Lists
- Searching Algorithms
- File Handling
- Classes and Objects
